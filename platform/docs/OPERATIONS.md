# 运维

## SLO

| 服务 | 指标 | 目标 |
|---|---|---|
| 数据中台 | 可用性 | 99.9% |
| 数据中台 | 特征查询 P95 | 小于 100ms |
| 评测中台 | 可用性 | 99.9% |
| 评测任务 | 成功率 | 大于 99% |

## 监控

- QPS、错误率、P95/P99；
- 质量任务失败数；
- 特征缺失率/过期率；
- 评测任务时长、失败率；
- Judge 调用成本。

## 故障

- PostgreSQL 不可用：服务返回 503，恢复后重试；
- 评测任务卡住：检查并发、Agent 超时、队列；
- 质量规则误杀：回滚规则版本，修数据后重跑；
- 特征过期：检查上游数据同步，不要绕过新鲜度检查。

## 发布

1. 数据库迁移；
2. 部署新版本；
3. 健康检查；
4. 灰度；
5. 观察质量、评测、错误率。
