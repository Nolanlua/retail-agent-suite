# 架构

## 分层

~~~text
业务 Agent
  → 数据中台（目录、质量、特征、血缘）
  → 评测中台（数据集、任务、指标、报告）
  → PostgreSQL / Redis / 对象存储
~~~

平台是横向能力层，不拥有业务语义。每个业务域通过 tenant_id 与 domain 隔离，平台只保存元数据、质量报告、特征快照和评测结果。

## 数据中台

- 数据资产：文档语料、表、特征视图、知识图谱；
- 质量：规则集、DAG/任务、失败阻断；
- 特征：门店-SKU-日期快照、新鲜度检查；
- 血缘：上游资产到下游特征。

## 评测中台

- 数据集：不可变版本；
- 任务：指向数据集版本；
- 指标：确定性优先，Judge 补充；
- 报告：通过率、均值、单条结果。

## 多租户

所有业务表带 tenant_id。平台管理员可跨租户运维，但不读取业务正文；业务用户只能看到自己租户的数据。

## 可靠性

- 所有下游调用有超时；
- 质量失败阻断特征发布；
- 评测任务可重试，结果可复现；
- 生产环境用任务队列，不用 asyncio.create_task；
- 健康检查、优雅关闭、统一错误契约。
