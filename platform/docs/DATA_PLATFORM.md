# 数据中台

## 能力

1. 数据目录：资产、负责人、敏感级别、版本；
2. 质量门禁：规则集、检查任务、失败阻断；
3. 特征服务：按业务日期取最近快照，检查新鲜度；
4. 数据血缘：上游、下游、作业、转换 SQL。

## 质量

数据质量规则是代码，和业务代码一起评审。检查失败时：

- 任务失败；
- 告警值班；
- 阻断特征发布；
- 记录报告供审计。

## 特征

~~~http
POST /v1/features/query
{
  "feature_view": "feature_replenishment_input",
  "store_id": "S01",
  "sku": "SKU-0001",
  "business_date": "2026-12-07T00:00:00Z"
}
~~~

返回 payload，包含特征版本和值。特征过期返回 404，业务 Agent 必须降级，不能拿旧数据计算。

## 血缘

每次特征发布和转换写入 lineage_edges。排障时可以从 Agent 指标反查上游资产和作业。

## 权限

- 资产目录：JWT + tenant；
- 质量任务、特征查询：内部服务令牌；
- 原始数据下载：单独审批；
- 敏感字段按列脱敏。
