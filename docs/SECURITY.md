# 安全

## 身份

- JWT 包含 subject、tenant_id、roles；
- 网关校验后注入 X-Tenant-Id；
- 内部服务使用服务令牌；
- Wiki 编辑和审核角色分离。

## 数据

- 按 public/internal/confidential 分级；
- 供应商价格、员工信息、内部制度属于敏感数据；
- 日志不打印 token、完整敏感正文；
- 导出/批量下载需审批。

## 合规

- 不承诺最低价；
- 不绕过商品召回；
- 不泄露内部文件/供应商底价；
- 价格、召回、陈列以系统和负责人最终确认为准；
- 召回、价格、陈列相关回答必须保留审计记录。

## 订单

- 下单必须带 Idempotency-Key；
- 订单、明细、幂等、Outbox 同事务；
- 唯一索引兜底；
- 外部供应商重试带幂等键。
