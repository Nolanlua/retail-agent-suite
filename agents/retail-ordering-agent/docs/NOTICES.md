# 公告与提醒

## 来源

零售智库知识库中的 approved notice 页面：

- 商品召回；
- 端头/陈列变更；
- 供货价调整；
- 新品上市；
- 供应商到货要求。

## 订货 Agent 处理

1. load_notices 调用智库 internal/notices；
2. apply_notices 做确定性判断：
   - 召回命中 SKU：建议量强制 0，生成 urgent 提醒；
   - 陈列变更：生成店长提醒，不直接改补货量；
   - 价格调整：生成商品专员提醒；
   - 新品：生成首铺提醒。
3. 回应返回 notices 和 reminders，由店长/专员处理。

## 为什么不让 LLM 直接改数

召回是硬规则，必须由代码保证。LLM 只负责解释公告和提醒，不负责决定“还能不能卖”。
