# 运维

## SLO

| 指标 | 目标 |
|---|---|
| Agent 可用性 | 99.9% |
| Agent P95 | 小于 2 秒 |
| 下单成功率 | 大于 99.5% |
| 特征新鲜度 | 小于 72 小时 |

## 监控

- 请求量、错误率、P95；
- 特征缺失/过期；
- 供应商 5xx；
- 订单幂等命中；
- Outbox 积压；
- 模型 token 成本。

## 故障

### 特征缺失

返回“数据未同步”，不计算补货，不拿旧数据凑。

### 供应商不可用

返回空 offers，建议量 0，标记 supplier_unavailable，转人工。

### 重复下单

查 idempotency_keys 和唯一索引；供应商侧对账。

### 本地落库失败

进入人工处理队列；生产补 Outbox 补偿 Worker。
