# 运维

## SLO

| 指标 | 目标 |
|---|---|
| 可用性 | 99.9% |
| P95 延迟 | 小于 3 秒 |
| 索引失败率 | 小于 0.5% |
| Wiki 审核积压 | 小于 24 小时 |

## 监控

- 请求量、错误率、P95；
- 检索命中数；
- 引用校验失败率；
- 合规拦截率；
- Wiki 审核积压、索引失败；
- 模型成本和超时。

## 故障

### 检索集群不可用

降级到另一路；两路都不可用返回“暂时无法检索”，不生成无依据回答。

### 索引失败

页面保持 approved，index_status=failed，运维重建索引。

### 公告未同步

订货 Agent 会标记 notice_unavailable；店长以系统公告为准，不自行猜测。
